# 全开源星球艺术数字藏品系统源码前端uniapp

源码获取：ym7k.com/19874/

## 一、技术架构

- 前端：Uniapp，一套代码编译 H5、微信小程序、APP
- 后端：ThinkPHP + FastAdmin 管理后台
- 数据库：MySQL
- 存储：支持阿里云 OSS、本地存储、对象存储
- 区块链适配：可对接联盟链（如蚂蚁链、文昌链等链上接口，用于藏品上链存证）

## 二、核心功能模块

### 1. 藏品铸造与发行

后台上传图片、3D 模型、音视频藏品素材；铸造藏品，设置藏品名称、介绍、版权方、发行总量、单价；支持普通发售、预约抽签、限量抢购模式；可设置发售时间、限购数量，防超发。

### 2. 盲盒模块

创建盲盒系列，配置盲盒内不同等级藏品（普通、稀有、史诗、传说），设置概率；用户购买盲盒开箱随机开出藏品，开箱动画展示。

### 3. 藏品合成玩法

配置合成配方，消耗指定多件藏品，合成全新高阶藏品，提升平台用户留存。

### 4. 用户端核心功能

微信一键登录，实名认证（可选开启）；首页轮播、新品藏品、盲盒专区、合成工坊、藏品分类；藏品详情预览（图片 / 3D 模型）、购买；我的藏品仓库，持有藏品展示；藏品转赠（给其他用户，后台可开关转赠功能）；订单中心、支付记录、收藏、浏览记录；邀请分享、推广海报。

### 5. 藏品集市（谨慎开启）

闲置藏品展示，**仅适合合规转赠展示**，不可做加价交易炒作；后台可独立开启 / 关闭集市功能，管控内容。

### 6. 版权方 / 艺术家入驻

艺术家申请入驻，后台审核；入驻创作者可提交作品，平台发行，设置分佣比例，作品售出后自动结算收益。

### 7. 后台管理功能

- 藏品管理：藏品、系列、盲盒、合成配方新增编辑上下架
- 用户管理：用户列表、实名审核、账号封禁
- 订单财务：购买订单、资金流水、创作者收益、提现审核
- 链上管理：链上存证接口配置、藏品上链记录查询
- 内容审核：藏品素材、用户昵称、评论敏感词过滤
- 营销配置：空投藏品、新人福利、活动配置
- 数据看板：发售数据、用户新增、销量统计图表

## 三、变现模式（合规方向）

✅ 藏品发售差价（文创数字艺术品售卖）
✅ 创作者藏品分佣
✅ 平台活动、品牌定制藏品发行服务
✅ 品牌方文创藏品定制

## 四、适用场景

✅ 文旅文创数字藏品平台（景区、博物馆文创）
✅ 艺术家、设计师数字作品发行收藏平台
✅ 品牌 IP 文创、企业纪念数字藏品发放
✅ 高校、社团文创数字作品展示平台

## 五、系统优势

✅ **全开源**，无加密代码，可自由阅读、修改、二次开发
✅ Uniapp 多端，小程序 + H5+APP 通用，切换终端成本低
✅ 玩法齐全：发售、抽签、盲盒、合成、转赠、创作者入驻
✅ 支持联盟链上链存证，生成链上凭证
✅ FastAdmin 后台成熟，权限、导出、上传组件齐全，运维简单
